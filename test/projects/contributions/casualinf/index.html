Replication: Zika and Birth Rates in Brazil, a Causal DiD Approach

• Estimated the causal effect of Zika virus on Brazilian birth rates using R.

• Used causal inference methods and packages in R to replicate the original paper’s results.

• Added municipal-level GDP data to compare the expanded approach with the original to see if this improved estimates. It did not.
